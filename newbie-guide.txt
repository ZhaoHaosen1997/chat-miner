============================================
  Chat-Miner 新手教程
  群聊内容分析工具 v{VERSION}
============================================

Chat-Miner 是一个群聊分析工具。导入微信/QQ 聊天记录后，
AI 会自动生成每日报告、群友画像、周报月报年报等有趣内容。

============================================
  第一步：导出聊天记录
============================================

【微信】使用 WeFlow 工具导出：
  1. 下载 WeFlow: https://github.com/Shuax/WeFlow
  2. 打开 WeFlow，选择要导出的群聊
  3. 导出格式选择 "ArkMe JSON"
  4. 导出后会得到一个 .json 文件

【QQ】使用 qq-chat-exporter 导出：
  1. 下载: https://github.com/shuakami/qq-chat-exporter
  2. 选择 V5+ 版本，导出 JSON 格式
  3. 私聊和群聊都可以导入

============================================
  第二步：导入数据
============================================

  1. 双击 ChatMiner.exe，会弹出一个黑框（服务器窗口）
  2. 浏览器会自动打开，进入 ChatMiner 首页
  3. 在首页点击 "上传聊天记录" 按钮
  4. 选择你导出的 .json 文件（也支持拖拽上传）
  5. 使用完毕后，关闭黑框即可退出程序

============================================
  第三步：配置大模型（最重要！）
============================================

Chat-Miner 需要大模型来生成分析报告。推荐使用在线 API，
只需要一个 API Key 就能用，不需要自己部署。

【推荐方案：DeepSeek 在线 API】
  1. 打开 https://platform.deepseek.com
  2. 注册账号，在 "API Keys" 页面创建一个 Key
  3. DeepSeek 价格很便宜，充 10 块钱能用很久
  4. 在 Chat-Miner 左侧菜单点击 "设置"
  5. 在 "在线模型" 卡片中粘贴你的 API Key
  6. 点击卡片上的 WiFi 图标测试连接
  7. 显示 "连通成功" 就完成了！

【也可以使用其他在线 API】
  在设置页点击 "添加模型"，填写：
  - 名称：随便起
  - 类型：在线
  - 端点：API 地址（如 https://api.openai.com/v1/chat/completions）
  - API Key：你的 Key
  - 模型名：如 gpt-4o

【高级用户：本地 Ollama】
  如果你已经安装了 Ollama，在设置页的本地模型卡片中
  就可以直接使用。但本地模型需要较好的显卡。

【端口冲突怎么办？】
  如果 8856 端口被其他程序占用，编辑 ChatMiner 文件夹下的
  config.json 文件，修改 port 字段，保存后重启即可。
  文件内容示例：
  {
    "port": 8858
  }

============================================
  第四步：开始分析
============================================

配置好模型后，回到首页：
  - 点击日历上的日期 → "开始 AI 分析" → 等待生成日报
  - 或者点击 "一键分析全部" 批量生成所有日期的日报
  - 左侧菜单可以查看 "群友画像"、"群鱼塘" 等

============================================
  更多功能
============================================

【事件探测】
  首页仪表盘会自动扫描群聊中的关键事件（决策、讨论、社交、
  公告、梗诞生等），点击事件可查看 AI 生成的故事化叙述。

【群梗百科】
  AI 会扫描群聊发现群内自创梗和黑话，生成候选条目。
  你可以在梗百科页面审核：确认收录或拒绝。
  已收录的梗会自动注入 AI 分析 Prompt，帮助 AI 理解群聊上下文。
  入口：首页 "梗百科" 卡片，或直接访问 /memes 页面。

【群友画像】
  点击 "群友画像" 查看所有群友的性格标签、说话风格、群内角色。
  点击某个群友进入详情页，可查看：
  - 活动热力图、消息长度分布、常用表情、高频词
  - 社交关系网络（互动排行 + AI 关系类型判断）
  - 考古挖掘（首条消息、最长发言、历史之最）
  - 画像版本历史

【跨群身份】
  如果同一个人在多个群，可以在画像页点击 "跨群关联"，
  将不同群的同一个人合并，生成综合人格分析。

【周报 / 月报 / 年报】
  首页仪表盘可以生成周报、月报、年报：
  - 周报：群聊头条、AI 锐评、奖项颁发、话题演变
  - 月报：深度推理 + 情绪自适应配色
  - 年报：年度主题 + 12 奖项 + 时光轴 + 词云

【群鱼塘】
  群鱼塘是一个养鱼小游戏，每个群友可以领养一条鱼：
  - 喂食、摸鱼、训练、探索、战斗
  - 天气系统、季节变化、黑市交易
  - 塘主可以升级设施、颁布法令、管理公告栏
  - 每日自动结算，生成鱼塘日报

============================================
  设置页面功能一览
============================================

设置页面有 5 个标签页：

【基础设置】
  - 默认群组：选择启动后默认显示的群
  - 在线模型配置：API Key、端点、模型名

【高级选项】
  - AI 模型分配：为日报和画像分别指定默认模型
  - 提示词管理：7 种提示词可自定义（日报/画像/周报/月报/年报/综合画像/事件探测）
  - 过滤词管理：自定义停用词，过滤无意义口语和昵称
  - WeFlow 同步设置：地址、令牌、同步间隔
  - 报告参数、超时设置等

【任务记录】
  - 查看所有分析任务的历史记录和状态

【鱼塘设置】
  - 自动事件开关、事件间隔
  - 作弊模式（测试用）
  - 公告栏编辑、自定义文案

【AI 日志】
  - 查看所有 AI 调用的详细记录
  - 按管线类型、任务、状态筛选
  - 查看每次调用的 Prompt 和 AI 响应
  - 支持清理旧日志

============================================
  常见问题
============================================

Q: 显示 "API Key 无效" 或 "余额不足"？
A: 检查 Key 是否正确粘贴，确认账户有余额。

Q: 生成报告很慢？
A: 在线模型通常 10-30 秒完成。如果超时，请检查网络。
   也可以在设置页增加超时时间。

Q: 能分析多个群吗？
A: 可以。在首页左上角可以切换群，也可以上传多个群的记录。

Q: 聊天记录安全吗？
A: 数据全部存储在你的电脑上（ChatMiner 同级 data 目录）。
   配置文件 config.json 也在 ChatMiner 文件夹中。
   使用在线 API 时，聊天文本会发送到 API 服务器进行处理。

Q: 如何升级到新版本？
A: 便携版：解压新版 zip 覆盖旧目录即可，数据不会丢失。
   安装版：运行新版 setup.exe，数据不会丢失。

Q: 如何退出程序？
A: 关闭弹出的黑框窗口即可。下次使用再次双击 ChatMiner.exe。

Q: 从旧版（源码版）迁移数据？
A: 将旧版的 data 文件夹复制到 ChatMiner 文件夹中即可。
   启动时会自动备份和兼容旧数据库。
   如果遇到报错，删除 data\chat_miner.db 重新导入。

Q: AI 分析结果不准确？
A: 可以在设置页自定义提示词，引导 AI 关注你关心的方向。
   也可以在梗百科中收录群内黑话，帮助 AI 理解上下文。

Q: 如何查看 AI 调用的详细信息？
A: 设置页 → "AI 日志" 标签页，可以查看每次 AI 调用的
   Prompt、响应、Token 用量和耗时。
